# サイトデザイン刷新計画 (Stylish Redesign Plan)

## ゴール
既存の「和モダン」な雰囲気を活かしつつ、**「奥行き」「動き」「余白」**を取り入れて、より洗練された「おしゃれ」なサイトへ進化させます。

## ユーザーレビューのお願い
以下のデザイン方針について、進めて良いか確認をお願いします。

## 提案する変更内容

### 1. 配色パレットのアップデート (Color Palette)
真っ白な背景は清潔感がありますが、少し冷たい印象になりがちです。
- **変更**: 背景色を `FFFFFF` から、わずかに温かみのある**エクリュ（生成り色）**や**グレージュ**に変更し、高級感を演出します。
- **変更**: アクセントカラー（茶色）をより深く、彩度を落としたトーンに調整し、モダンな印象にします。

### 2. タイポグラフィ（文字）の洗練
- **[NEW] 欧文フォントの導入**:
  数字や英語の見出し用に、エレガントなセリフ体（例: `Cormorant Garamond` や `Playfair Display`）をGoogle Fontsから導入します。これにより、日本語の明朝体と相まって「雑誌のような」美しさが生まれます。
- **文字間隔の調整**: 見出しの `letter-spacing` をさらに広げ、ゆったりとした「間」を作ります。

### 3. 動き（モーション）の追加
静的なページは寂しい印象を与えます。
- **スクロールアニメーション**: 画面に入ったタイミングで画像やテキストが「ふわっ」と浮き上がるフェードイン効果を追加します。
- **画像の演出**: 写真をただ置くのではなく、ゆっくりとズームする動きや、枠線をずらしたデザインなどを取り入れます。

### 4. 具体的なファイル変更計画

#### [MODIFY] `src/styles/design-tokens.css`
- カラー変数の更新
- フォントファミリー変数の追加（欧文用）

#### [MODIFY] `src/App.svelte`
- Google Fontsの読み込みリンク（`<link>`タグ）を`<svelte:head>`に追加

#### [NEW] `src/styles/animations.css`
- フェードイン、スライドインなどの汎用アニメーションクラスを定義

#### [MODIFY] コンポーネント群 (`src/components/`)
- 各コンポーネントにアニメーションクラスを適用

### 5. メニューボタンとナビゲーションの実装
- **[NEW] 波打つメニューボタン**:
  - 右上に固定表示されるハンバーガーメニューのようなボタンを作成（`MenuButton.svelte`）。
  - **モーション**: 開閉時やホバー時に、水面が波打つような有機的な動き（`border-radius`のアニメーションやSVGフィルターを使用）を取り入れます。
- **メニュー項目**:
  以下の項目へ遷移するメニュー画面を実装します。
  1. **私達について**
  2. **取引形態**
  3. **流れ**
  4. **物件一覧**
  5. **実例集**
  6. **スタッフブログ**

## 検証計画
### 手動検証
- `npm run dev` を使用してブラウザでプレビュー。
- スマートフォン表示（responsiveness）での崩れがないか確認。
- アニメーションが重くないか、スムーズかを確認。
